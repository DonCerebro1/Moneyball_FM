
# FM Moneyball Suite ⚽📊

Willkommen zum ersten offiziellen Release der **FM Moneyball Suite**! 

Dieses Tool hilft dir dabei, deine Squad- und Scouting-Daten aus dem Football Manager datenbasiert nach Moneyball-Prinzipien zu analysieren, Transferentscheidungen zu optimieren und Entwicklungen über mehrere Spielzeiten hinweg nachzuvollziehen.

---

### Features & Highlights
* **Datenbasierte Kaderanalyse:** Berechnet individuelle Moneyball-Scores für taktische Rollen auf Basis relevanter Leistungs- und Attributdaten.
* **Scouting & Transfer-Check:** Schneller Preis-Leistungs-Vergleich für potenzielle Neuzugänge und Gehaltsforderungen.
* **Historie & Snapshots:** Speichere Importe pro Transferfenster und verfolge Entwicklungen von Attributen und Noten über die Zeit.
* **Excel-Export:** Generiere übersichtliche `.xlsx`-Reports für deine Kaderplanung.
* **Integrierter Update-Checker:** Erkennt automatisch neue Versionen direkt beim Programmstart.
* **Keine Installation nötig:** Standalone-Paket inklusive Java-Laufzeitumgebung.

---

### Installation & Erste Schritte
1. Lade die unten angehängte Datei **`FMMoneyball.zip`** herunter.
2. Entpacke das Archiv an einen beliebigen Ort (z. B. Desktop oder Dokumente – *nicht* in `C:\Program Files`).
3. Starte die Anwendung über die Datei **`FMMoneyball.exe`**.
